Nothing should look different, but we've made a lot of changes under the hood!

### Hosting & Infrastructure

- Frontend now runs on [Cloudflare Workers](https://developers.cloudflare.com/workers/) and is powered by the [Astro framework](https://astro.build). This provides us better caching and slims down the app considerably. You should see significant performance gains this season as a result.
- The game processing API is now our only service to run on DigitalOcean. 
- Our summary service (serving percentiles, team metrics, leaderboards, etc) has been deprecated in favor of using the same data from [sportsdataverse.org](https://sportsdataverse.org).
- The game data API (IE: sending a HTTP `POST` to `/cfb/game/<id>`) has been deprecated. If you need this data for whatever reason, please reach out to us.

### New Features

- All models updated: EPA, WPA, xQBR, etc.
- Fourth down bot recommendations are now integrated into play rows. 
- Touchdown plays now have two-point recommendations integrated.
- The Adj EPA chart has been upgraded into a full blown [chart builder](/charts/builder) that supports all team metrics.
- Matchup previews have been expanded into a full-blown [matchup builder](/game/builder).

## Known Issues

- Some dropdowns on team pages might not work (metric selection, year selection).
- The Adj EPA model is still being reworked.
