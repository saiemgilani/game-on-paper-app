# pr-previews

Screenshot previews embedded in pull-request comments. Never merged; safe to
delete once the PRs they illustrate are closed.

Each `prNNN/` holds the repo's visual-check matrix — desktop 1280x800 and
mobile 390x844, in light and dark (`prefers-color-scheme` emulation) — as
full-page JPEGs plus above-the-fold `-thumb` crops.
